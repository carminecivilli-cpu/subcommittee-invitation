# Subcommittee Invitation

Professional invitation page for the initial BIARGS and ALRTS working groups.

## Invitation links

- BIARGS: `?group=biargs&token=INVITATION_TOKEN`
- ALRTS: `?group=alrts&token=INVITATION_TOKEN`

The page is connected to a private Google Apps Script response service. Do not
store invitee names, email addresses, PINs, credentials, or private spreadsheet
data in this public repository.
